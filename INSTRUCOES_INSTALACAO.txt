# 📋 SEQUÊNCIA DE INSTALAÇÃO E INICIALIZAÇÃO

Siga os comandos abaixo na ordem exata para configurar o projeto. O sistema utiliza sua GPU NVIDIA para o processamento da IA e a CPU para a busca no banco de dados, garantindo máxima performance e estabilidade no Windows.

---

## 1. Configuração do Backend (Python)

Abra um terminal na pasta raiz do projeto:

```bash
# 1. Criar ambiente virtual
python -m venv env

# 2. Ativar o ambiente virtual
# No Windows:
env\Scripts\activate

# 3. Instalar dependências
pip install -r requirements.txt
pip install faiss-cpu

# 4. Criar banco de dados e usuário Admin
python create_admin.py
```

---

## 2. Configuração do Frontend (React)

Abra um SEGUNDO terminal na pasta `frontend`:

```bash
# 1. Instalar dependências do Node
npm install
```

---

## 3. Configuração dos Modelos de IA (Obrigatório)

O sistema utiliza o modelo **Qwen 2.5 3B** (4.1B parâmetros).

1. **Baixe o Modelo**: [Clique aqui para baixar o qwen2.5-3b-instruct-q4_k_m.gguf](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/main/qwen2.5-3b-instruct-q4_k_m.gguf)
2. **Localização**: Coloque o arquivo baixado na pasta `C:\Users\SEU_USUARIO\.cache\llama.cpp`.
3. **Nota**: Você usará este mesmo arquivo para os dois servidores (Chat e Busca).

---

## 4. Como Rodar o Sistema (4 Terminais)

### Terminal 1: Servidor de Embedding (Porta 8081)
```bash
# Use o caminho completo da sua pasta de usuário
llama-server -m C:\Users\andre\.cache\llama.cpp\Qwen3-Embedding-0.6B-Q8_0.gguf --embedding --port 8081
```

### Terminal 2: Servidor LLM (Porta 8080)
```bash
# Use o caminho completo da sua pasta de usuário
llama-server -m C:\Users\andre\.cache\llama.cpp\qwen2.5-3b-instruct-q4_k_m.gguf --port 8080 -fa 1 -c 32768 -ngl 99
```

### Terminal 3: Backend Python (Porta 8000)
```bash
python main.py
```

### Terminal 4: Frontend React (Porta 5173)
```bash
cd frontend
npm run dev
```

---

## 🛠 Guia de GPU (NVIDIA)

O sistema já está configurado para extrair o máximo da sua **RTX 3050**:
1. O comando `-ngl 99` carrega 100% da IA na VRAM da placa de vídeo.
2. A leitura de PDFs (porta 8081) também processa via hardware.
3. Certifique-se de ter o **CUDA Toolkit** instalado para que os modelos `.gguf` rodem com aceleração.

---

## 🛠 Solução de Erros Rápidos

- **Erro de FAISS**: Se o sistema disser "Could not import faiss", rode: `pip install faiss-cpu`.
- **Porta 8000 ocupada**: Feche outros terminais Python ou reinicie o PC.
- **Login falhou**: Delete o arquivo `ucdb_ia.db` e rode o `python create_admin.py` novamente.

  - Senha: `admin123`
